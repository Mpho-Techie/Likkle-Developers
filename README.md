# CASH-LINK

## 💳 Point. Scan. Pay.

**CashLink** is a digital real cash-to-point web application designed to bridge the gap between South Africa's informal cash economy and formal digital payments. It allows users to convert real money into digital points and pay local businesses (spaza shops, taxis, hawkers) using simple QR code scans – **without requiring bank accounts, data-heavy apps, or changes to daily habits.**

---

## Problem Statement

Millions of South Africans engage in informal economic activities but remain excluded from the formal financial system due to:

- **High banking fees** (monthly account fees, transaction costs)
- **Complexity** of traditional banking apps
- **Data costs** for heavy applications
- **Established cash habits** that are hard to change

---
## Solution
A simple, points-based system that mirrors cash transactions while introducing digital convenience.

---

## ✨ Core Features

| Feature | Description |
|---------|-------------|
| **Points-based currency** | 1 Rand = 1 Point – simple, intuitive exchange |
| **QR Code Payments** | Scan any merchant QR code to pay instantly |
| **Cash Top-Ups** | Convert physical cash to digital points at participating agents |
| **Transaction History** | View all payments and top-ups chronologically |
| **No Bank Account Required** | Works entirely with cash-to-points conversion |
| **Low Data Usage** | Lightweight HTML/CSS/JS, works on basic smartphones |
| **Offline Capable** | Core functionality works without continuous internet |

---

## 🖥️ Technology Stack

| Layer | Technology |
|-------|-------------|
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| QR Scanning | HTML5-QRCode Scanner Library |
| Data Persistence | Browser localStorage |
| Styling | Custom CSS (No frameworks – fast & light) |
| Deployment | Static web hosting (Netlify, GitHub Pages, etc.) |

---

### Installation (Zero Setup Required)

1. **Download** `CashLink.html` to your computer or phone
2. **Double-click** to open in your browser
3. **Register** a new account
4. **Top up** points (simulated cash conversion)
5. **Scan QR codes** to make payments
